# Каталог стилей · PW Hub

Распознавание стилей Perfect World по скриншоту каталога. Обработка выполняется в браузере.

## Запуск

Node.js 22.12+ ветки 22 или 24+, pnpm 9.15.9. Поддерживаются современные Chrome и Edge.

```sh
corepack enable
corepack prepare pnpm@9.15.9 --activate
pnpm install --frozen-lockfile
pnpm dev
```

Адрес: `http://127.0.0.1:5100`. Сервер доступен только на локальном компьютере. Вместо Corepack можно использовать `npx --yes pnpm@9.15.9`.

Сборка: `pnpm build`. Предпросмотр: `pnpm preview`, адрес `http://127.0.0.1:5101`.

При запуске и сборке `scripts/prepare-ocr.mjs` копирует OCR-ресурсы в `public/ocr/`. Исходные файлы `eng.traineddata` и `rus.traineddata` нужны для сборки. Готовое приложение работает без CDN и не отправляет изображения на сервер.

## Использование

1. Выберите пол персонажа.
2. Загрузите PNG, JPEG или WebP либо начните захват окна игры.
3. При необходимости задайте ширину карточки вручную. Кнопка «Остановить» отменяет захват и обработку.

Результаты можно фильтровать по статусу сбора. В диагностике доступны исходный текст OCR, уверенность и время обработки.

Название сверяется со справочником. Неуверенные и неоднозначные совпадения отклоняются. Счётчик `5/5` означает собранный стиль, `3/5` — несобранный. Нечитаемый счётчик остаётся неопределённым. Цвет фона используется только для поиска карточек.

Справочник неполный. Цены и курсы требуют проверки в игре. Способы получения указаны не для всех стилей.

## Ограничения

- Файл: до 20 МБ и 16 млн пикселей.
- Обработка: один активный кадр и один ожидающий; устаревшие кадры пропускаются.
- Результаты: до 120 карточек, до 36 областей на кадр.
- OCR: не более двух работников.

Карточки должны быть видны целиком. Другие темы оформления, масштаб и размытие могут мешать распознаванию.

## Код

| Каталог         | Назначение                                                          |
| --------------- | ------------------------------------------------------------------- |
| `src/domain/`   | Типы, проверка данных, названия, счётчики и объединение результатов |
| `src/imaging/`  | Размеры изображения, сегментация и подготовка текста в Worker       |
| `src/services/` | OCR, захват экрана и отмена операций                                |
| `src/session/`  | Сессии, очередь и освобождение ресурсов                             |
| `src/ui/`       | Карточки и вывод изображений                                        |

Правила разработки: [CONTRIBUTING.md](CONTRIBUTING.md).

## Проверки

```sh
pnpm check
pnpm test:coverage
pnpm exec playwright install chromium
pnpm test:e2e
pnpm benchmark
pnpm audit
```

`check` запускает линтер, типизацию, проверку справочников, тесты, сборку и форматирование. Браузерные тесты используют локальный OCR; захват моделируется через `canvas.captureStream`.

Для проверки OCR используются `tests/fixtures/card.png`, её варианты и изображения `partial-*.png` с фиксированными счётчиками. Полный игровой каталог этим набором не охвачен. Отчёты сохраняются в `reports/`, `coverage/` и `playwright-report/`. Проверки GitHub Actions настроены в [`.github/workflows/quality.yml`](.github/workflows/quality.yml).

## Патч Tesseract

Версия `7.0.0` закреплена из-за патча `patches/tesseract.js@7.0.0.patch`. Он добавляет отмену через `AbortSignal` и завершение работников при ошибке загрузки языка или WASM. Патч применяется pnpm при установке.

При обновлении библиотеки проверьте, нужен ли патч, и запустите тесты отмены, ошибок загрузки и повторной попытки.
