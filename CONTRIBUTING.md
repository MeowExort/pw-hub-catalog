# Разработка

Инструкции запуска и структура кода описаны в [README.md](README.md).

## Предложения изменений

Об ошибках и предложениях можно сообщать через Issues. Приём стороннего кода требует отдельного соглашения с MeowExort о правах на его коммерческое использование. До такого соглашения изменения от сторонних авторов не включаются в проект. Отправка pull request сама по себе не передаёт авторские права.

## Окружение и проверки

Используйте pnpm 9.15.9 и Node.js 22.12+ ветки 22 или 24+. Версия для разработки закреплена в `.node-version`.

Перед коммитом запускайте `pnpm check`. При изменениях распознавания, очереди или работы с ресурсами дополнительно выполняйте `pnpm test:coverage`, `pnpm test:e2e` и `pnpm benchmark`. После обновления зависимостей запускайте `pnpm audit`.

## Требования к изменениям

- Сообщения коммитов и комментарии пишите по-русски. Для коммитов используйте Conventional Commits.
- Сохраняйте стабильные `id` записей справочника. Цены, валюты и курсы проверяются при сборке.
- Результат старой сессии не должен изменять новую. Ожидающие задачи отменяются при остановке.
- Работники, видеопотоки и Blob URL освобождаются при завершении работы.
- Сбор подтверждается счётчиком `N/N`. Цвет фона используется только для сегментации.
- Неуверенные названия и счётчики остаются неопределёнными.
- OCR-ресурсы поставляются со сборкой. Сервисы разработки слушают только локальный интерфейс.
- При изменении поведения обновляйте README. Порядок обновления патча Tesseract описан там же.

Готовые сборки, отчёты и тестовые изображения из `tests/fixtures/generated/` в Git не добавляются. Исходные изображения, языковые модели и патчи должны оставаться в проекте.
